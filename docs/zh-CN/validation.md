## 测试分组

测试覆盖影像几何与 I/O、数值算子、优化器和完整配准流程。CPU FP64 与 ANTs `--float 0` 对照，CPU FP32、Metal 和 CUDA 与 `--float 1` 对照。

```bash
python -B scripts/maintenance/run_tests.py --suite core
python -B scripts/maintenance/run_tests.py --suite cpu-fp64
python -B scripts/maintenance/run_tests.py --suite cpu-fp32
```

Metal 测试需要 Apple GPU：

```bash
python -B scripts/maintenance/run_tests.py --suite metal
```

CUDA 测试需要 NVIDIA GPU 和 CuPy：

```bash
python -B scripts/maintenance/run_tests.py --suite cuda
```

小范围改动可通过 `--pattern` 选择相关文件。分组说明见[测试目录](../../tests/README.zh-CN.md)。

## 数值测试

算子测试使用小数组和已知变换，检查插值、物理梯度、平滑、局部统计、直方图导数、形变场复合和求逆。测试点应包含图像内部与边界；常量图像、近常量区域、大坐标原点和各向异性网格有助于发现数值问题。

完整配准可使用具有已知位移的合成变换。正向和逆向映射都要检查，同时确认单位和复合顺序。不同后端的浮点规约可能产生小幅差异，比较时关注数值误差及最终对齐效果，不要求优化轨迹逐步相同。

## 图像与地标对齐

在同一固定图像网格、同一前景区域上评估不同实现。已保存结果的评估工具计算以下指标：

| 指标 | 含义 |
| --- | --- |
| 归一化互相关（NCC） | 重采样后的强度相似性，越大表示相关性越强 |
| 归一化均方误差 | 强度归一化后的残差，越小表示越接近 |
| 目标配准误差（TRE） | 对应地标经变换后的距离，单位为毫米 |

设固定图像地标为 `p_i`、对应移动图像地标为 `q_i`，固定到移动的映射为 `T`，则

```math
\mathrm{TRE}_{\mathrm{RMS}}=\sqrt{\frac{1}{N}\sum_i\|T(p_i)-q_i\|^2}.
```

图像相似性与地标误差反映不同方面的对齐情况。报告结果时，说明图像统计所用区域及地标标注来源。

## 形变场质量

位移场 `u` 的空间 Jacobian 为 `J=I+∇u`。检查行列式的最小值，以及行列式非正的体素数量。内置质量统计分别评估非线性的正向场和逆向场。

逆一致性通过复合两侧映射后的残差计算：

```math
r(x)=\phi^{-1}(\phi(x))-x.
```

两个复合方向都需要检查，在复合采样有效的位置统计 RMS、百分位数或最大位移，单位为毫米。同时检查形变场、重采样图像和统计结果是否为有限值。这些指标保存在 `quality.json` 或独立评估报告中，仍需结合配准图像进行目视检查。

## 评估数据

评估示例使用三份 IXI T1 图像：IXI002-Guys-0828、IXI012-HH-1211 和 IXI013-HH-1212，尺寸为 256×256×150。[输入信息](../../validation/sources/input-inventory.json)、[下载校验值](../../validation/sources/downloaded-files.json)和[数据来源](../../validation/sources/public-data.json)记录文件及预处理方法。附带地标为粗略标注。

原始 IXI 数据使用 CC BY-SA 3.0。Zenodo 再发布页面对新增材料标注 CC BY 4.0；MRI 文件应遵循原始数据集的许可。影像数据不包含在 Python 软件包中。

## CUDA 检查

`tests/cuda` 包含 CUDA 算子与完整配准测试，在 NVIDIA 硬件上设置 `FAST_ANTS_TEST_CUDA=1` 启用。检查范围包括图像采样、滤波、Mattes 控制、场运算、逆场停止、状态保留、保存变换重应用和原生 FP64 最终 QA。真实 MRI 的保存结果在计时结束后使用共同的 CPU FP64 采样器评估，检查前景相似度、探索性标记点、正逆 Jacobian 及逆一致性。

## Apple M5 原始 MRI 结果

[Apple M5 测量](performance.md#apple-m5-发布版本测量)使用 256×256×150 原始分辨率 IXI 图像对和 10 线程。已保存结果先与公开计时记录的输出校验值及运行记录核验，再由同一 CPU FP64 采样器重新应用。前景掩膜取固定图像强度范围 5% 以上的 3,236,832 个体素。配准前前景 NCC 为 0.171354，四个粗略地标的平均误差为 21.4895 mm。

| 引擎 | 前景 NCC | 平均地标误差 / mm | 正逆 Jacobian 最小值 | 逆一致性 RMS 最大值 / mm |
| --- | ---: | ---: | ---: | ---: |
| Metal FP32 | 0.662625 | 1.4299 | 0.165859 | 0.022969 |
| CPU FP32 | 0.664474 | 1.4382 | 0.160806 | 0.023699 |
| CPU FP64 | 0.664417 | 1.4345 | 0.161804 | 0.023478 |
| ANTs FP32 | 0.664369 | 1.4315 | 0.160959 | 0.023638 |
| ANTs FP64 | 0.664417 | 1.4345 | 0.161804 | 0.023478 |

Metal 地标误差的 RMS 和最大值分别为 1.8645 和 3.3925 mm，ANTs FP32 分别为 1.8650 和 3.3914 mm。前景归一化均方误差分别为 0.013558 和 0.013509。四个地标来自非专家粗略标注，这些数值描述该图像对的对齐结果。

所有引擎的正逆场和重采样图像均为有限值，与固定网格一致。正向和逆向 Jacobian 均为有限正值，非正体素数均为 0。末列取两个非线性复合方向中较大的 RMS。Metal 正向和逆向 Jacobian 最小值分别为 0.165859 和 0.179500。每个方向的逆一致性统计均使用全部 9,830,400 个网格点：

| 复合顺序 | Metal RMS / mm | ANTs FP32 RMS / mm | Metal P99 / mm | ANTs FP32 P99 / mm | Metal 最大值 / mm | ANTs FP32 最大值 / mm |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 正向场作用于逆向场之后 | 0.022969 | 0.023638 | 0.083221 | 0.085717 | 0.392295 | 0.409191 |
| 逆向场作用于正向场之后 | 0.020985 | 0.021935 | 0.077979 | 0.081582 | 0.478370 | 0.489421 |

逆一致性残差反映映射及其逆映射复合后接近恒等变换的程度，地标误差反映标注点的对齐情况。[Apple M5 数据](../assets/benchmarks/v0.1.0-native.json)记录两类指标、逐点误差、输出校验值和评估来源。保存结果评估在原计时之外进行，性能表仍为 v0.1.0 的单次测量。
