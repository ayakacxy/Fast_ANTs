# 开发计划

[English](../en/roadmap.md) · [简体中文](roadmap.md) · [文档目录](index.md)

## 支持的功能

- 三维刚体、仿射和标准 greedy SyN 配准。
- 线性阶段使用 Mattes 互信息，SyN 使用局部互相关。
- CPU FP64、CPU FP32 和 Apple Metal FP32 计算。
- 图像金字塔、仿射与位移场读写、图像重采样和质量统计。
- 命令行与 Python 接口、JSON 预设和英文进度日志。

## NVIDIA CUDA

CUDA 后端计划采用 FP32 体素计算，复用配准算法和 Python 接口。

1. **设备运行时。** 增加设备数组管理、kernel 启动、stream／event、分配复用和显式主机／设备传输。CUDA 依赖保持可选，仅在选择该后端时加载。
2. **基础算子。** 实现三线性和最近邻采样、坐标映射、图像梯度、高斯滤波，以及计数、求和和最大范数归约。
3. **相似性度量。** 移植固定分箱 CSR 索引、局部 PDF、流式 Mattes MI 导数和 GPU 度量终结处理；增加中心化局部 CC 统计和双向更新。
4. **形变场与 SyN。** 实现场重采样、缩放复合、逆残差与受限更新，再接入四场 SyN 循环和多分辨率状态调整。复用层内工作区，图像和场保留在 GPU 上。
5. **流程与异步执行。** 将 CUDA 算子接入共享主机模型和优化器，通过 stream 重叠独立的准备和传输，在需要度量值和停止决策时同步。增加后端选择，不改变 CPU 或 Metal 的依赖。
6. **测试与计时。** 将算子和保存的配准结果与 CPU 实现、同精度官方 ANTs 比较，检查图像相似性、地标误差、Jacobian 和逆一致性。在 NVIDIA 硬件上执行完整配准测试，记录编译／预热、同步、输入输出和设备型号。

FP64 支持取决于目标 GPU 的能力与应用需求，需要单独评估数值误差和性能。CUDA 运行时库及依赖尚未选定。

## 其他后续工作

- 补充不同配准方向、体素间距和采集设置的使用示例。
- 增加不同操作系统及依赖版本上的 CPU 自动化测试。
- 完善 CPU 与 Metal 后端的逐迭代日志。
- 分析度量计算、形变场操作、内存分配和 GPU 同步的开销。
- 补充预设与 API 示例，保持 CLI 和 Python 的参数处理一致。

Fast ANTs 专注于图像配准和变换应用，分割、皮层厚度等神经影像分析组件不在项目范围内。
