# 开发计划

[English](../en/roadmap.md) · [简体中文](roadmap.md) · [文档](index.md)

## 支持的功能

- 三维刚体、仿射和标准 greedy SyN 配准。
- 线性阶段使用 Mattes 互信息，SyN 使用局部归一化互相关。
- CPU FP64、CPU FP32、Apple Metal FP32 和 CUDA FP32 计算。
- 图像金字塔、仿射与位移场读写、图像重采样和质量统计。
- 命令行与 Python 接口、JSON 预设和英文进度日志。

CUDA 支持 FP32 刚体、仿射和 SyN 配准，最终场质量检查使用 FP64。

Linux 与 Windows 实测结果见[性能测试](performance.md)和[测试与质量评估](validation.md)。

## v0.4.0：质量评估与批处理

验证范围限定为 MRI，计划按以下优先顺序实施：

### 1. 多病例质量评估

使用现有 Fast ANTs 算法进行标准数据验证。官方 ANTs 对照保留在已发布的基准中，本项仅运行 Fast ANTs。

- 使用 [LPBA40](https://loni.usc.edu/research/atlases) 等人工标注数据建立可复现的病例清单，覆盖不同图像方向、体素间距和采集设置。
- 将变换后的移动图像标签与固定图像的人工标签比较，报告标签 Dice、NCC、有标注时的地标误差、Jacobian 统计、失败率和耗时分布，分别统计首次运行与缓存运行。
- 完成标准：能够从病例清单复现逐例结果及汇总报告，记录输入来源、配置和软件版本。

### 2. 环境诊断与自动测试

- 增加 `fast_ants doctor`，检查 Python、依赖和设备可用性，并在选定的 CPU、CUDA 或 Metal 后端执行小型计算。
- 在 Windows、Linux 和 macOS 自动检查普通 wheel 安装、CLI 和小型 CPU 配准；GPU 检查在对应硬件上执行。
- 完成标准：测试覆盖安装后的软件包及运行资源；诊断能够定位依赖缺失或运行库故障，并报告实际计算结果。

### 3. 批量配准

- 增加由病例清单驱动的批处理命令，支持逐例输出、单例失败后继续、断点续跑和汇总报告。
- 评估进程与编译缓存复用，以批次总耗时、峰值内存和峰值显存衡量性能。
- 完成标准：恢复运行时跳过已完成病例，保留失败记录；在相同设置下，批处理与独立运行的逐例结果在数值容差内一致。

## 后续方向

- 增加 CUDA FP64 拟合，并验证更多 NVIDIA 设备。
- 完善 CPU 与 Metal 后端的逐迭代日志。
- 分析度量计算、位移场操作、内存分配和 GPU 同步的开销。
- 补充预设与 API 示例，保持 CLI 和 Python 的参数处理一致。
